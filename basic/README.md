# # Restaurant API Project

## Overview

A beginner-friendly REST API built with FastAPI for learning API Design Fundamentals.

The application simulates a restaurant menu system and demonstrates how modern APIs receive requests, process data, and return JSON responses.

---

## Training Level

Beginner / Fundamentals

---

## Learning Objectives

By completing this lab, learners will understand:

* REST API fundamentals
* FastAPI framework basics
* HTTP methods (GET and POST)
* API endpoints
* Request and response bodies
* JSON data exchange
* Pydantic data validation
* Error handling
* Swagger/OpenAPI documentation

---

## Real-World Analogy

| Restaurant Concept | API Concept         |

## Features

### 1. Home Endpoint

Purpose:

Verify that the API server is running.

Method:

GET

URL:

/

Example Response:

{
"message": "Restaurant API Running Successfully"
}

---

### 2. Get Menu Endpoint

Purpose:

Retrieve all available menu items.

Method:

GET

URL:

/api/v1/menu

Example Response:

[
{
"id": 1,
"name": "Burger",
"price": 250
},
{
"id": 2,
"name": "Pizza",
"price": 450
},
{
"id": 3,
"name": "Pasta",
"price": 350
}
]

---

### 3. Create Menu Item Endpoint

Purpose:

Add a new item to the restaurant menu.

Method:

POST

URL:

/api/v1/menu

Example Request Body:

{
"name": "Shawarma",
"price": 300
}

Example Response:

{
"message": "Menu item added successfully",
"item": {
"id": 4,
"name": "Shawarma",
"price": 300
}
}

## Installation

Create Virtual Environment

python -m venv venv

Activate Virtual Environment

Windows:

venv\Scripts\activate

Linux / macOS:

source venv/bin/activate

Install Dependencies

pip install -r requirements.txt

---

## Running the Application

Start the FastAPI development server:

uvicorn app_basic:app --reload

Server URL:

http://127.0.0.1:8000

---

## Important Notes

This application uses in-memory storage.

Menu items are stored in a Python list and are not persisted.

Any newly created menu items will be lost when the application restarts.

Future versions of this project will introduce:

* Path parameters
* Query parameters
* PUT operations
* DELETE operations
* Database integration
* PostgreSQL
* SQLAlchemy ORM
